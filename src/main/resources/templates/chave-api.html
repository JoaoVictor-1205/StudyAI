Cole a chave criada no Google AI Studio. Normalmente ela começa com AIza.

Desmarcada, a chave fica só nesta aba. O navegador ainda pode restaurá-la se a aba ou a sessão for reaberta, então, em computadores compartilhados, clique em Remover chave antes de sair ou use uma janela anônima.

Onde a chave fica

  • Fica salva somente neste navegador, no armazenamento do StudyAI.
  • Vai para o servidor apenas quando você pede uma geração, e ele a repassa ao Gemini nessa mesma chamada.
  • Não é gravada no banco de dados, em arquivos nem na sessão do servidor.
  • Quem usar este navegador pode gerar respostas com ela. Remova a chave quando não precisar mais.
  • Se o navegador oferecer salvar a chave como senha, recuse para mantê-la só no armazenamento do StudyAI.
  • Na camada gratuita do Gemini, o Google pode usar o conteúdo enviado para melhorar os produtos dele. Evite materiais com dados pessoais ou sigilosos.
